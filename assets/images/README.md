# Vos photos — MAISON KM

Déposez vos photos dans **ce dossier** (`assets/images/`) en respectant
**exactement** les noms de fichiers ci-dessous. Dès qu'un fichier est présent,
la photo remplace automatiquement le visuel SVG de repli — **aucune
modification de code n'est nécessaire**.

- Format conseillé : **JPG** (ou PNG), carré ~**1000×1000 px** pour les montres
  et les collections, **fond clair** pour rester dans l'esprit pastel.
- Le hero peut être plus large (paysage, ~2000×1200 px).

### Changer un nom / ajouter un produit
Les noms de fichiers sont définis dans `assets/js/main.js` (champ `image` de
chaque objet des listes `MONTRES`, `COLLECTIONS`, `ACCESSOIRES`). Modifiez-y la
valeur si vous voulez un autre nom de fichier.
