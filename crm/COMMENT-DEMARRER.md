# 🚀 Démarrer le CRM en 3 étapes

Aucune connaissance technique nécessaire. Suivez dans l'ordre.

## Étape 1 — Installer Node.js (une seule fois)

1. Allez sur **https://nodejs.org**
2. Cliquez sur le gros bouton **« LTS »** pour télécharger
3. Ouvrez le fichier téléchargé et installez (Suivant → Suivant → Terminer)

> C'est le « moteur » qui fait tourner le CRM. À faire une seule fois.

## Étape 2 — Récupérer le CRM

1. Allez sur **https://github.com/kix4210069/moh**
2. En haut, cliquez sur la branche et choisissez **`claude/crm-formation-apprentis-nzc0yg`**
3. Cliquez sur le bouton vert **« Code »** puis **« Download ZIP »**
4. **Décompressez** le fichier ZIP (double-clic dessus)
5. Ouvrez le dossier `moh` → puis le dossier **`crm`**

## Étape 3 — Lancer le CRM

Dans le dossier `crm`, **double-cliquez** sur :

- 🪟 **Windows** → `Lancer-le-CRM.bat`
- 🍏 **Mac** → `Lancer-le-CRM.command`

Une fenêtre noire s'ouvre (c'est normal), puis le CRM s'ouvre tout seul dans votre navigateur.

> 🍏 **Sur Mac**, si un double-clic ne lance rien : **clic droit** sur le fichier → **Ouvrir** → **Ouvrir** (à faire une seule fois, c'est une sécurité de macOS).

## ✅ Vous y êtes !

- Adresse : **http://localhost:3000**
- Identifiant : **admin@centre.fr**
- Mot de passe : **admin1234**

### Ensuite, dans le CRM :
1. **Paramètres** → mettez les infos de votre centre (nom, SIRET…)
2. **Apprentis** → créez une fiche, ajoutez la photo, l'état du dossier
3. **Documents** → générez le CERFA et la convention en PDF
4. **Collaborateurs** → invitez vos collègues (et retirez l'accès quand ils partent)

> ⚠️ Tant que le CRM tourne sur votre ordinateur, l'adresse `localhost:3000` ne
> fonctionne **que pour vous**. Pour le partager à vos collaborateurs par un lien,
> il faudra le mettre en ligne — dites-le moi quand vous serez prêt(e).
